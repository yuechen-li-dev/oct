# Draft privacy policy — owner fields required

**Publisher, public privacy URL, support email, legal entity and hosting/subprocessor list must be supplied by the deployment owner before publication.** This draft must be reviewed by the owner’s counsel.

Oct MCP receives Oct source, bounded project files, tool arguments, compiler diagnostics, stdout/stderr, generated artifacts, request metadata needed for abuse prevention, and service logs. It processes this data to compile, run, diagnose, return artifacts, operate the service, and investigate abuse. Artifacts are retained in memory for up to ten minutes; source workspaces are deleted after the request. The application does not intentionally persist source or artifacts beyond that period. Deployment logs and ingress telemetry retention are owner-configured and must be stated at the published URL.

The service does not use customer source/artifacts for model training. It does not require an end-user account in the anonymous MVP. If the owner later enables authentication, the published policy must identify identity data, provider, retention and deletion procedure. The owner must list hosting, observability, CDN, authentication and other subprocessors before publication.
