# ZImageTurboMainTransformer0

Focused M2C Oct contracts for the representative `layers.0` joint MainTransformer
stream. The numerical authority remains the pinned FP32 canonical laboratory;
these contracts pin only user-visible source semantics: image-first composition,
the two position domains, and the four-way AdaLN ordering.

## Json migration (2026-10-07)

`WriteM2CJointContractWitness` published a JSON text literal through
`Json.Object`. It publishes a `JointContractWitness` record, whose fields are
spelled as the schema `oct.prometheus.evt2.m2c.oct-joint-contract.v1` spells
its keys. `m2c_oct_joint_contract.json` is regenerated: the same keys in the
same order with the same values, in the layout `Json` writes.
